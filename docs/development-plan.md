# xBaoNotes 分阶段开发计划 v1.0

目标：不要一口气做太多，每个阶段都能独立验证，确保项目稳定、安全、有效推进。

## Phase 0：文档和项目规则

目标：建立需求、技术、设计、执行标准和开发日志。

交付：

- `AGENTS.md`
- `docs/requirements.md`
- `docs/technical-spec.md`
- `docs/design-guidelines.md`
- `docs/development-plan.md`
- `docs/execution-standards.md`
- `dev-logs/progress.md`
- `dev-logs/todo.md`

验收：

- 用户能看到完整开发规划。
- 后续开发有明确文档依据。

## Phase 1：项目基础骨架

目标：创建可启动的 Windows 桌面应用骨架。

交付：

- Tauri 2 + Rust + React + TypeScript + Vite 基础项目。
- 主窗口能启动。
- 基础路由或页面结构。
- 日间、黑夜、跟随系统主题框架。
- 安装包层面预留 WebView2 检测方案。

验收：

- 应用可在本机启动。
- 主页面不是空白。
- 主题切换可见。

## Phase 2：本地数据层

目标：建立稳定的数据保存能力。

交付：

- SQLite 数据库初始化。
- 默认数据目录创建。
- 设置读取和保存。
- 文件夹表和便签表。

验收：

- 新建数据后重启应用仍存在。
- 数据目录位于用户可理解的位置。

## Phase 3：主页面基础管理

目标：实现便签管理基础闭环。

交付：

- 4 种便签类型的列表。
- 类型切换：全部、普通便签、待办、时间轴、富文本笔记。
- 新建、编辑、重命名、删除、置顶。
- 标题搜索。
- 文件夹分类。

验收：

- 每种类型都能新建和编辑。
- 标题搜索有效。
- 置顶排序有效。
- 文件夹筛选有效。

## Phase 4：回收站和安全删除

目标：避免误删数据。

交付：

- 删除进入回收站。
- 回收站页面。
- 恢复。
- 彻底删除。
- 清空回收站。
- 回收站路径设置。

验收：

- 删除后能恢复。
- 彻底删除前有确认。
- 回收站路径可配置。

## Phase 5：富文本、图片和附件

目标：让内容编辑能力达到可长期使用标准。

交付：

- 富文本编辑器。
- 完整表格能力。
- 图片拖入和预览。
- 附件拖入和附件卡片。
- 附件复制到软件管理目录。

验收：

- 图片和附件重启后仍可打开。
- 表格编辑可用。
- 富文本内容保存正确。

## Phase 6：桌面贴出便签

目标：实现用户最核心的桌面便签体验。

交付：

- 单条便签独立窗口。
- 位置和尺寸保存。
- 默认置顶。
- 手动取消置顶。
- 重启后恢复贴出窗口并自动置顶。

验收：

- 贴出窗口可移动、缩放。
- 重启后恢复状态正确。
- 主页面和贴出窗口内容同步。

## Phase 7：贴边入口、托盘和启动行为

目标：实现默认贴边隐藏入口和系统级体验。

交付：

- 贴边入口窗口。
- 上、下、左、右贴边。
- 鼠标靠近展开。
- 快速切换便签类型。
- 托盘入口。
- 开机自启动开关。
- 启动方式设置。

验收：

- 默认启动显示贴边入口。
- 可从入口打开主页面。
- 开机自启动可开启和关闭。

## Phase 8：提醒系统

目标：实现不同便签类型的提醒能力。

交付：

- 普通便签指定时间提醒。
- 待办截止时间、重复提醒、过期提醒。
- 时间轴纪念日和回顾提醒。
- 富文本笔记复习提醒。
- Windows 通知。

验收：

- 提醒重启后仍有效。
- 重复规则可配置。

## Phase 9：密码锁和备份恢复

目标：提高数据安全和容灾能力。

交付：

- 密码锁。
- 自动锁定时间。
- 关闭密码锁。
- 手动备份。
- 从备份恢复。
- 备份路径设置。

验收：

- 密码锁可开启和关闭。
- 备份文件可生成。
- 恢复前会保护当前数据。

## Phase 10：打包、测试和优化

目标：形成可安装、可日常使用的版本。

交付：

- Windows 安装包。
- 基础测试清单。
- 异常处理。
- 空状态优化。
- 性能检查。

验收：

- 可安装。
- 可卸载。
- 核心功能稳定。
- 用户数据不会因升级丢失。
