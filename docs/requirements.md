# xBaoNotes 产品需求文档 v1.0

## 1. 产品定位

`xBaoNotes` 是一个面向 Windows 的本地便签软件。用户不需要懂代码，不需要账号，也不需要云同步。软件重点是快速记录、桌面贴出、贴边快速入口、分类管理、提醒、安全和本地备份。

## 2. 已确认原则

- 软件名称：`xBaoNotes`。
- 使用范围：仅本地 Windows 使用。
- 默认启动：显示贴边隐藏的小入口。
- 启动方式可配置：贴边入口、主页面、最小化到托盘、记住上次状态。
- 支持开机自启动，并可在设置中关闭。
- 贴出的便签重启后恢复贴出窗口，并自动重新置顶。
- 支持密码锁，可在设置中关闭。
- 支持本地备份，备份路径可选。
- 默认备份路径：`Documents\xBaoNotes\Backup`。
- 支持软件自己的回收站，回收站路径可选。
- 默认回收站路径：`Documents\xBaoNotes\Recycle Bin`。
- 搜索范围：搜索标题。
- 文件夹可包含多种类型便签。
- 图片、附件支持拖入便签。

## 3. 便签类型

### 3.1 普通便签

用于快速记录文字、图片、附件。支持指定时间提醒。

### 3.2 待办

用于记录任务清单。支持勾选完成、截止时间、提醒、过期提示和可选重复规则。

重复规则在设置提醒时选择，至少包括：

- 不重复
- 每天
- 每周
- 每月
- 每年
- 自定义

### 3.3 时间轴

采用类似朋友圈动态流的形式，支持文字、图片、附件。用于日记、生活记录、项目过程记录、事件记录。

时间轴必须支持按日期筛选：

- 按天
- 按月
- 按年

### 3.4 富文本笔记

用于较完整的笔记记录。需要支持：

- 标题
- 加粗、斜体、下划线
- 字体颜色和高亮
- 有序列表和无序列表
- 图片
- 附件
- 完整表格能力
- 拖拽插入图片和附件

## 4. 主页面

主页面需要支持按类型筛选：

- 全部
- 普通便签
- 待办
- 时间轴
- 富文本笔记

主页面基础功能：

- 新建
- 编辑
- 重命名
- 删除
- 置顶
- 标题搜索
- 文件夹分类
- 移入回收站
- 从回收站恢复

## 5. 文件夹

文件夹可以包含不同类型的便签。例如一个“工作”文件夹中可以同时包含普通便签、待办、时间轴和富文本笔记。

文件夹功能：

- 新建文件夹
- 重命名文件夹
- 删除文件夹
- 移动便签到文件夹
- 按文件夹筛选显示

## 6. 桌面贴出

每条便签都可以单独贴到桌面上。

贴出便签要求：

- 单独窗口显示
- 可拖动位置
- 可调整大小
- 默认置顶
- 支持手动取消置顶
- 软件重启后恢复贴出窗口
- 软件重启后自动重新置顶
- 内容与主页面保持一致

## 7. 贴边隐藏入口

软件默认启动后显示贴边隐藏的小入口。

贴边入口要求：

- 支持贴在屏幕左、右、上、下边缘
- 鼠标靠近后展开
- 展开后显示所有便签类型入口
- 可快速打开普通便签、待办、时间轴、富文本笔记
- 可进入主页面
- 可在设置里修改贴边位置和启动行为

## 8. 主题

支持三种主题模式：

- 日间模式
- 黑夜模式
- 跟随系统

## 9. 图片和附件

便签、时间轴和富文本笔记都应支持拖入图片和附件。

要求：

- 拖入图片后可预览
- 拖入附件后显示文件名和文件图标
- 点击附件可打开
- 附件随便签一起保存
- 删除便签时附件一起进入软件回收站或保留可恢复状态

## 10. 回收站

删除内容时先进入软件回收站，不直接永久删除。

回收站要求：

- 查看已删除内容
- 恢复
- 彻底删除
- 清空回收站
- 回收站路径可在设置中修改

默认路径：

```text
Documents\xBaoNotes\Recycle Bin
```

## 11. 备份

支持本地备份。

备份要求：

- 可选择备份路径
- 默认备份到用户 Documents 目录下的 `xBaoNotes\Backup`
- 支持手动备份
- 支持从备份恢复
- 后续可扩展定时自动备份

默认路径：

```text
Documents\xBaoNotes\Backup
```

## 12. 密码锁

支持密码锁，可在设置里关闭。

密码锁要求：

- 启动软件时可要求输入密码
- 从贴边入口打开主页面时可要求输入密码
- 支持自动锁定时间
- 支持修改密码
- 支持关闭密码锁

说明：第一版密码锁优先实现“软件访问保护”。如需防止他人直接读取本地数据文件，应单独规划“数据加密”阶段。

## 13. 当前不做的功能

- 不做账号系统。
- 不做云同步。
- 不做手机端。
- 不做多人协作。
