# xBaoNotes v1.0.0

首个正式版，提供 Windows 安装版和便携版。

## 主要功能

- 本地 SQLite 数据保存，不需要账号和云同步。
- 普通便签、待办、时间轴、富文本笔记。
- 标题搜索、文件夹分类、置顶、回收站。
- TipTap 富文本编辑，支持图片、附件和表格。
- 单条便签可贴出为桌面窗口，支持置顶、移动、缩放和重启恢复。
- 贴边隐藏入口，支持上、下、左、右位置。
- 系统托盘入口和安装版开机自启动开关。
- 提醒系统，支持指定时间、截止、重复、纪念日和复习提醒。
- 密码锁、自动锁定、修改密码和关闭密码锁。
- 手动备份和从备份恢复，恢复前自动保护当前数据。
- 日间、黑夜、跟随系统主题。

## 便携版

- 便携版 zip 内包含 `portable.flag`。
- 便携版所有数据保存在软件所在目录。
- 便携版默认禁用开机自启动。
- 如果便携目录不可写，软件会提示移动到可写目录后运行。

## 下载文件

- `xBaoNotes_1.0.0_x64-setup.exe`：推荐普通用户使用的 Windows 安装包。
- `xBaoNotes_1.0.0_x64_en-US.msi`：MSI 安装包。
- `xBaoNotesPortable_1.0.0_x64.zip`：便携版，解压后运行 `xbao-notes.exe`。

## 注意

- 密码锁是软件访问保护，不是完整磁盘级数据加密。
- Windows 通知需要系统允许通知权限。
- Windows 10 可能需要 Microsoft Edge WebView2 Runtime。
