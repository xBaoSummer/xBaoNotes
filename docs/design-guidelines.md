# xBaoNotes UI/交互设计规范 v1.0

## 1. 设计方向

整体风格参考 Windows 11 / Fluent Design，目标是轻量、清晰、现代、适合长期停留使用。

设计关键词：

- 清楚
- 安静
- 轻量
- 圆角
- 柔和阴影
- 高可读性
- 低干扰

## 2. 字体

Windows 默认优先：

```text
Segoe UI
Microsoft YaHei UI
```

中文界面应保证字距自然，避免过小字号。

## 3. 主题

支持三种模式：

- 日间模式
- 黑夜模式
- 跟随系统

主题实现应使用统一设计变量，例如：

- 背景色
- 面板色
- 文本主色
- 文本次色
- 边框色
- 强调色
- 悬停色
- 选中色
- 阴影

## 4. 主窗口布局

建议主窗口采用三栏或两栏增强布局：

- 左侧：文件夹、回收站、设置入口。
- 顶部：搜索、类型切换、新建按钮。
- 中间：便签列表。
- 右侧或弹出编辑区：当前便签内容。

类型切换使用单选式分段控件：

- 全部
- 普通便签
- 待办
- 时间轴
- 富文本笔记

## 5. 便签列表

每条便签列表项应显示：

- 标题
- 类型
- 所属文件夹
- 更新时间
- 置顶状态
- 提醒状态

置顶便签显示在列表上方。

## 6. 桌面贴出便签

桌面便签窗口要求：

- 小型独立窗口
- 默认置顶
- 可移动
- 可缩放
- 有清晰标题栏
- 支持关闭贴出但不删除内容
- 支持手动取消置顶

按钮应优先使用图标：

- 置顶
- 取消置顶
- 收起
- 关闭贴出
- 更多菜单

## 7. 贴边入口

贴边入口默认启动显示。

收起状态：

- 只显示窄条或小按钮。
- 根据屏幕边缘调整方向。
- 不遮挡主要工作区域。

展开状态：

- 显示普通便签、待办、时间轴、富文本笔记入口。
- 显示打开主页面按钮。
- 显示快速新建按钮。

## 8. 富文本编辑器

富文本工具栏应包含：

- 标题级别
- 加粗
- 斜体
- 下划线
- 字体颜色
- 高亮
- 有序列表
- 无序列表
- 表格
- 插入图片
- 插入附件

工具栏按钮使用图标加悬浮提示。

## 9. 时间轴

时间轴样式类似动态流：

- 按时间倒序展示。
- 支持图片预览。
- 支持附件卡片。
- 支持按天、月、年筛选。
- 日期分组清晰。

## 10. 可访问性

需要注意：

- 文本和背景对比度足够。
- 按钮点击区域不小于 32px。
- 深色模式下边框和阴影不能过重。
- 所有图标按钮需要悬浮提示。

## 11. 禁止事项

- 不做复杂花哨动画。
- 不使用过度鲜艳的大面积渐变。
- 不让文字和按钮重叠。
- 不在小面板中使用过大的标题字号。
- 不把关键功能藏在难发现的位置。
