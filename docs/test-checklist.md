# xBaoNotes 测试清单 v1.0

用于 Phase 10 打包、测试和优化。每次正式发布前至少按本清单抽查。

## 1. 构建检查

- `npm.cmd run build` 成功。
- `cargo test` 成功。
- `npm.cmd run tauri -- build` 成功。
- 生成 `src-tauri\target\release\xbao-notes.exe`。
- 生成 MSI 安装包。
- 生成 NSIS 安装包。

## 2. 启动和窗口

- 启动后默认显示贴边入口。
- 可从贴边入口打开主页面。
- 可从托盘打开主页面。
- 主窗口关闭后隐藏到后台，托盘仍可打开。
- 贴边入口支持左、右、上、下位置。

## 3. 便签管理

- 普通便签、待办、时间轴、富文本笔记均可新建。
- 标题、类型、文件夹、内容可保存。
- 重启后便签仍存在。
- 标题搜索有效。
- 文件夹筛选有效。
- 置顶和取消置顶有效。

## 4. 回收站

- 删除便签进入回收站。
- 回收站中可恢复便签。
- 彻底删除前有确认。
- 清空回收站前有确认。
- 彻底删除后附件文件被清理。

## 5. 富文本和附件

- 加粗、斜体、下划线、文字颜色、高亮、列表可用。
- 表格插入、增行、增列、删除表格可用。
- 图片拖入后可预览。
- 普通附件拖入后显示附件卡片。
- 点击附件可用系统默认程序打开。
- 重启后附件仍可访问。

## 6. 桌面贴出

- 便签可贴出为独立窗口。
- 贴出窗口可移动和缩放。
- 贴出窗口位置和尺寸可保存。
- 手动取消置顶有效。
- 重启后恢复贴出窗口并自动置顶。

## 7. 提醒

- 普通便签可创建指定时间提醒。
- 待办可创建截止提醒和重复提醒。
- 时间轴默认纪念日提醒可保存。
- 富文本笔记默认复习提醒可保存。
- 到期后弹出 Windows 通知。
- 一次性提醒触发后停用。
- 重复提醒触发后推进下一次时间。

## 8. 密码锁

- 可开启密码锁。
- 启动后显示锁屏。
- 密码错误无法进入。
- 密码正确可以解锁。
- 可修改密码。
- 可关闭密码锁。
- 自动锁定和立即锁定可用。
- 锁定时贴出窗口关闭，解锁后恢复。

## 9. 备份恢复

- 可选择备份目录。
- 可创建手动备份。
- 备份目录包含 `Data`、`Attachments`、`Recycle Bin` 和 `backup-manifest.json`。
- 备份列表显示最近备份。
- 恢复备份前会确认。
- 恢复前会自动创建 `Before Restore` 保护备份。
- 恢复后数据、附件、回收站状态与备份一致。

## 10. 视觉和可用性

- 日间模式文字可读。
- 黑夜模式文字可读。
- 主要按钮不重叠。
- 小窗口宽度下按钮可换行。
- 路径文本不会撑破设置面板。
- 空列表有可理解的空状态。

## 11. 便携版

- 便携版 zip 中包含 `xbao-notes.exe` 和 `portable.flag`。
- 从便携目录启动后，界面显示数据模式为便携版。
- 便携版数据库创建在 `xBaoNotesPortable\Data\xbao-notes.sqlite3`。
- 便携版附件保存到 `xBaoNotesPortable\Attachments`。
- 便携版备份保存到 `xBaoNotesPortable\Backup`。
- 便携版回收站路径为 `xBaoNotesPortable\Recycle Bin`。
- 便携版开机自启动不可开启。
- 删除 `portable.flag` 后不再按便携版路径规则运行。
