# xBaoNotes Docs

本目录保存项目开发相关标准文档。所有需求、技术选型、UI 规范和执行步骤都应在这里维护。

## 文档索引

- `requirements.md`：产品需求和用户确认事项。
- `technical-spec.md`：技术路线、数据存储、窗口、提醒、备份、安全等实现标准。
- `design-guidelines.md`：Windows 11 风格、主题、布局、控件和交互规范。
- `development-plan.md`：分阶段开发步骤和每阶段验收标准。
- `execution-standards.md`：开发流程、日志更新、测试和质量标准。

## 更新规则

需求变化时先更新文档，再开发。每次开发完成后，同步更新 `dev-logs/progress.md` 和 `dev-logs/todo.md`。
